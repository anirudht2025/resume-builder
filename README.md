## Project Steps

1. Create project using Vite.

2. Clear unwanted codes and files.

3. Install necessary node packages.
   - Install Material UI
   - Add Bootstrap CDN link
   - Add Google Fonts CDN link
   - Install React Icons
   - Update `index.css`
   - Update website icon & title

4. Create a folder for pages. Create components for main pages.

5. Create a folder for components. Create components such as Header, Footer, etc.

6. Provide paths to page components using `react-router-dom`.

7. Design components.

8. To make API calls.
   - Create `api` folder inside `src`
     - `axiosInstance.js`
     - `apiService.js`
   - Create `services` folder inside `src`
     - `allApiServices.js`

9. Create JSON Server as the backend.

10. Design the User Form page.

11. Implement form validation.

12. Add resume details using API.

13. Implement dynamic routing.

14. Display the selected resume using its ID.

15. Generate resume PDF using `html2canvas` and `jsPDF`.

16. Save download history.

17. Design the Download History page.

18. Implement Resume Edit functionality.

19. Add and remove technical skills.

20. Delete download history.

21. Configure custom JSON Server (`index.js`).

22. Deploy backend on Render.

23. Deploy frontend on Vercel/Render.
